Connect Claude

Claude app web · desktop · phone

  1. In Claude, open Settings → Connectors → Add custom connector.
  2. Name: Folio. URL:
    {{.MCPURL}}
  3. Keep Sign in now and Use Claude's published identity, then click Add.
  4. Folio opens: you're already logged in, so click Allow. Done.

Claude Code

claude mcp add -s user --transport http folio {{.MCPURL}}

Then run /mcp in Claude Code, pick folio and choose Authenticate. Your browser opens this site to approve.
